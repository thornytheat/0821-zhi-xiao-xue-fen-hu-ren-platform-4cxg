# 职校学分互认台

继续教育教务员可在工作台上传来源 CSV，对照规则判断差异，签发合格批次或记录暂缓意见。

用最大权重课程匹配确认互认学分，避免同一门外校课程重复抵扣。

支持同一申请跨批次补录：已签发配对冻结保留，同一外校课/校内课跨批次只抵扣一次；撞课时自动换组配对，达到本批最低学分仍可签发；并发撞课只有一批成功，另一批重新核算；回执重试幂等，不重复计学分。工作台可查询每个补录批次的签发结论与原因，详见 [阶段接口](docs/HTTP.md)。

## 启动

```sh
docker compose up --build -d --wait
```

打开 <http://localhost:18320>。页面预览带异常样例。选中阶段查看计算证据，选择可签发样例并执行批次，然后提交复核意见。

## 核验
